# `docs/media/` — every image, with the command that made it

Every file in this folder, what produced it and the release it shows. Nothing here is in Git LFS, and
every reference from a markdown file is a relative path (`docs/media/…`), so crates.io rewrites it to
this repository and the pictures show on the crate's page too.

Every picture comes from `examples/gallery` (`options.gif` from `examples/options`, `scope.gif` from
`examples/scope`, `density.gif` from `examples/density`, `ladder.gif` from `examples/ladder` and `popover.gif` from `examples/popover`, which have the same capture knobs), the crate's own capture path: `GOOEY_FRAMES=<n>`
saves one still at frame `n` to `GOOEY_SHOT`, and `GOOEY_SHOT_DIR=<dir>` keeps every
`GOOEY_SHOT_EVERY`th frame from `GOOEY_SHOT_FROM` there as `f_%04d.png` for a GIF. `GOOEY_SIZE`
sets the window, `GOOEY_SKIN` the preset, and `GOOEY_KEYS` stages the input each shot shows.

## The skins

The presets are one line each: `GOOEY_SKIN=parchment` or `GOOEY_SKIN=high_contrast` starts in that one (dark
is the default), and `GOOEY_TEXT_SCALE=1.5` shows the player's text-size option. The parchment skin is in
the README only as the right half of `dialog.png` and in `theme.gif`; the high-contrast one is in
`theme.gif` and `high-contrast.png`; the 1.5x text size has no picture here. A still of the whole
gallery in parchment is the capture a docs change would add next.
